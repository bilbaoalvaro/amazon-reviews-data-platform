# Data

The project uses Amazon 5-core review datasets in JSON format:

- Toys and Games
- Video Games
- Digital Music
- Musical Instruments
- Grocery and Gourmet Food (used for the new-dataset insertion step)

The original datasets are not included in this repository because of their
size and dataset redistribution considerations.

Place the expected JSON files in this directory before running the loading
scripts. The filenames are configured in `config.py`.
